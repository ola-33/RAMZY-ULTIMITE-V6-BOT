Command centre

Simple to use.

Commands use the default . prefix. Send a command in the WhatsApp chat with your bot to try the matching feature.

.menuShow available commands
.pingCheck bot response
.timeShow local time
.botstatusCheck bot status
.ownerOwner information
.groupinfoGroup information
.adminsList group admins
.tagallGroup tagging (permission-limited)
.stickerCreate a sticker from a quoted image
.guessStart a guessing game
.quizStart a quiz
.aiAI reply, if configured
