# RAMZY ULTIMATE V6 BOT

Starter project for the Ramzy Ultimate V6 Bot website and loading screen.

## What's included
- Node.js + Express web server
- Neon-green Ramzy loading screen shown on every page refresh
- `/health` endpoint for checking whether the web service is running
- Render-friendly start script

## Deploy to Render
1. Open Render and choose **New + → Web Service**.
2. Connect the GitHub repository `ola-33/RAMZY-ULTIMITE-V6-BOT`.
3. Runtime: Node; build command: `npm install`; start command: `npm start`.
4. Deploy and open the URL Render provides.

## Important
This is a starter website, not yet a connected WhatsApp bot. WhatsApp pairing and commands are a later step. Never put WhatsApp session credentials, API keys, or passwords in public GitHub files.
